# Bfarm Custom App

Ứng dụng tùy biến cho hệ thống quản lý nông nghiệp Bfarm trên nền tảng Frappe/ERPNext.

## Tính năng chính
- Bản dịch tiếng Việt chuẩn ngữ cảnh nông nghiệp.
- Tự động chuyển hướng người dùng thẳng vào Workspace **Bfarm Agriculture** sau khi đăng nhập.
- Thiết kế giao diện hợp nhất (Unified Agriculture Workspace) giúp thao tác nhanh mọi nghiệp vụ mà không cần chuyển đổi module.
- Tự động thay đổi thương hiệu navbar sang phong cách nông nghiệp premium.
